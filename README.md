# Demand Forecasting for Event and Business Bookings

This repository contains the dataset and Python notebook used for the bachelor thesis:

**Demand Forecasting for Event and Business Bookings in the Hospitality Industry: A Case Study of De Hofdame**

## Repository Contents

* `De Hofdame - Forecasting Demand.ipynb` – Complete forecasting workflow and analysis
* `Hofdame Historical Booking Data.xlsx` – Dataset used in the study

## Study Overview

The objective of this study was to evaluate the performance of SARIMA and SARIMAX forecasting models for predicting hospitality demand using historical booking data from De Hofdame, a hospitality venue located in Leeuwarden, the Netherlands.

The analysis includes:

* Data preprocessing and aggregation
* Daily demand forecasting exploration
* Weekly demand forecasting
* SARIMA modelling
* SARIMAX modelling with exogenous variables
* Routine-demand modelling using capped demand values
* Forecast evaluation using MAE and RMSE
* Forecast visualisation

## Software

The analysis was conducted in Python using Jupyter Notebook. The notebook contains all code required to reproduce the forecasting analysis presented in the thesis.

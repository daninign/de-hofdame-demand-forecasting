# Demand Forecasting for Event and Business Bookings

This repository contains the Python notebook used for the model fitting and forecasting analysis for the bachelor thesis *Demand Forecasting for Event and Business Bookings in the Hospitality Industry: A Case Study of De Hofdame*.

The notebook includes data preprocessing, weekly aggregation, feature engineering, SARIMA and SARIMAX model fitting, model evaluation, and forecast visualisation.

## Tools used

* Python
* pandas
* NumPy
* statsmodels
* holidays
* scikit-learn
* Matplotlib
* Jupyter Notebook
